# 音效素材说明

祈福动画使用的音效文件。

## 文件清单

| 文件名 | 用途 | 建议来源 |
|--------|------|----------|
| appear.mp3 | 财神现身（编钟/古筝） | 免版权音效库 |
| incense.mp3 | 进香（木鱼声） | 免版权音效库 |
| kowtow.mp3 | 磕头（低沉鼓点） | 免版权音效库 |
| blessing.mp3 | 祝福礼成（寺庙大鼓收束+礼成大钟+真实钱币录音，G大调） | scripts/gen-sound.py + scripts/coin-shower-cc0.mp3 (CC0) |
| bgm.mp3 | 背景氛围（古筝轻音乐） | 免版权音效库 |

## 规格要求

- 格式：MP3
- 短音效：≤ 3秒，≤ 100KB
- 祝福音乐：≤ 5秒，≤ 100KB（礼成收束，G大调与 BGM 同音阶，寺庙大鼓承接磕头+礼成钟福到+真实CC0钱币录音预示来财，殿堂混响与磕头同源）
- 背景音乐：≤ 30秒（循环），≤ 500KB
