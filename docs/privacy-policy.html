引言

欢迎您使用麻神赐福（以下简称"本应用"或"我们"）。我们深知个人信息对您的重要性，并将按照《中华人民共和国个人信息保护法》《中华人民共和国数据安全法》《中华人民共和国网络安全法》及华为应用市场（AppGallery Connect）相关规范的要求，采取相应的安全保护措施，致力于保护您的个人信息安全可控。

本《隐私政策》（以下简称"本政策"）将帮助您了解：

  • 我们会收集您哪些个人信息？为什么收集？
  • 我们如何使用收集到的信息？
  • 我们如何存储和保护您的个人信息？
  • 您如何管理您的个人信息？
  • 我们如何处理未成年人的信息？
  • 本政策如何更新？
  • 如何联系我们？
请您在使用本应用前，仔细阅读并充分理解本政策。一旦您选择使用本应用，即视为您同意我们按照本政策处理您的相关信息。

本政策与 App 内展示的隐私政策（我的 → 隐私政策）内容一致。如您对本政策有任何疑问，可通过文末"联系我们"中提供的方式与我们沟通。

一、我们收集哪些信息

为向您提供祈福排行榜、心愿墙等云端功能，本应用会收集以下信息：

信息类型收集内容收集方式使用目的
祈福者昵称 您在祈福时输入的姓名，仅存储脱敏形式（首字 + ***，如"张***"），不展示完整姓名 您主动提供 在祈福排行榜、心愿墙展示您的昵称
设备匿名标识符 应用首次启动时随机生成的匿名 ID（非 OAID/IMEI，不包含设备型号、序列号等可识别设备的信息） 自动生成 区分不同用户的祈福记录与心愿归属，实现排行榜与心愿墙功能
祈福行为数据 祈福次数、磕头次数、连续签到天数 自动收集 统计并生成祈福排行榜
心愿内容 您在心愿墙发布的许愿 / 还愿文字 您主动提供 实现许愿、还愿功能，并向所有用户公开展示

以下信息仅存储在您的设备本地，不上传：祈福历史、最近使用名称、签到记录、求签记录、牌运记录、日记便签、成就徽章等本地记录。

二、权限与传感器说明

为提供完整功能，本应用申请以下系统权限并读取传感器。各权限的目的、方式、范围说明如下，均不涉及额外信息收集或上传：

2.1 加速度传感器（摇动数据）

项目说明
目的检测摇晃手机的动作以完成「摇签求签」
方式仅在您进入求签页且应用处于前台时实时读取；应用退至后台即停止读取并释放传感器占用
范围摇动数据在设备本地即时判断后即丢弃，不上传、不存储、不用于其他用途；退出求签页即停止读取
对应权限ohos.permission.ACCELEROMETER
是否必需否。若您拒绝授权，仍可使用本应用的全部功能，仅无法使用「摇一摇求签」

2.2 网络

项目说明
收集内容仅传输本政策「一、」所述数据（脱敏昵称、匿名标识符、行为数据、心愿内容）
使用场景同步祈福排行榜、心愿墙等云端功能数据
对应权限ohos.permission.INTERNET
是否必需否。您可选择不使用排行榜、心愿墙等联网功能，其余功能均可离线使用

2.3 振动

项目说明
收集内容无。仅触发设备振动马达，不收集任何数据
使用场景在磕头祈福等互动场景中提供触感震动反馈，增强仪式感
对应权限ohos.permission.VIBRATE
是否必需否。若您拒绝授权，仍可使用本应用的所有功能，仅缺少震动触感反馈

2.4 修改音频设置

项目说明
收集内容无。仅控制音频播放，不录制或上传任何音频
使用场景播放祈福背景音乐、敲钟、木鱼等音效，并控制音量大小
对应权限ohos.permission.MODIFY_AUDIO_SETTINGS
是否必需否。若您拒绝授权，仍可使用本应用的所有功能，仅缺少音效播放
传感器数据说明：加速度传感器读取的摇动数据仅用于识别「摇一摇求签」动作，在设备本地即时判断后即丢弃，不上传、不存储，不构成对您个人信息的收集。您可在系统「设置 → 应用管理 → 麻神赐福 → 权限」中随时关闭加速度传感器权限。

三、我们如何使用收集的信息

  • 祈福统计、脱敏昵称与设备匿名标识符上传至华为云服务器（AppGallery Connect 云服务），用于生成并展示祈福排行榜
  • 心愿内容上传至华为云服务器，并在心愿墙向所有用户公开展示，用于实现许愿 / 还愿功能
  • 除上述云端功能外，其余记录仅存储在您的设备本地，用于为您展示历史回顾与提升输入体验
  • 本应用不接入任何广告、统计或第三方数据分析 SDK，不会将您的信息用于广告营销

四、我们如何存储和保护您的个人信息

4.1 存储位置

数据类型存储位置说明
脱敏昵称、匿名标识符、行为数据、心愿内容华为云服务器（AppGallery Connect 云服务，中国境内节点）用于排行榜与心愿墙功能，受华为云安全措施保护
祈福历史、签到、求签、牌运、便签等记录设备本地仅保存在您的设备上，卸载应用即自动清除

4.2 安全措施

  • 云端数据存储于华为云服务器，受华为云平台安全机制保护
  • 姓名仅以脱敏形式（首字 + ***）上传展示，不存储完整姓名
  • 本应用不接入任何第三方广告 / 统计 / 推送 SDK
  • 您可以随时删除已发布的心愿；卸载应用将自动删除设备本地数据

4.3 共享与跨境

本应用不与任何第三方共享您的个人信息；数据仅由华为云（AppGallery Connect 云服务）处理与存储，部署于中国大陆区域，不涉及跨境传输。除法律法规另有规定或经您另行同意外，我们不会对外提供您的个人信息。

五、您如何管理您的个人信息

权利方式
删除心愿内容在心愿墙删除自己发布的心愿，删除后云端记录一并移除
清除本地记录在 App 内「清除历史」等入口清除，或卸载本应用以清除全部本地数据
拒绝提供昵称您有权拒绝提供姓名，仅影响排行榜与心愿墙中的展示效果，不影响其他功能使用
撤回权限授权设备「设置 → 应用管理 → 麻神赐福 → 权限」中关闭对应权限（如加速度传感器）
特别说明：关闭或撤回授权后，对应功能（如摇一摇求签、排行榜同步）将不可用，但不会影响您此前已同意处理的合法性基础，也不会影响其他功能的使用。

六、未成年人保护

  • 本应用为祈福文化体验类应用，功能与内容适合所有年龄段用户使用
  • 本应用不主动收集未成年人的个人信息，不含任何不适合未成年人的内容（无暴力、无赌博、无不良引导）
  • 如您是未满 14 周岁的未成年人，建议在监护人陪同下使用本应用，并在监护人同意后再使用心愿墙等需上传内容的功能
  • 若监护人认为本应用存在任何不妥，可随时通过卸载应用停止使用，并可通过文末联系方式要求删除相关数据

七、本政策的更新

我们可能适时修订本政策，更新后将在本页面发布最新版本，并在 App 内公示。重大变更（涉及收集信息范围扩大、使用目的变更等）我们将通过应用内通知等方式醒目告知。

重大变更包括但不限于：

  • 服务模式发生重大变化（如处理个人信息的目的、类型、方式）
  • 个人信息共享、转让、公开披露的主要对象变更
  • 您参与个人信息处理方面的权利及行使方式变更
  • 处理个人信息的责任部门、联系方式发生变化

如您不同意修订后的内容，您可以停止使用本应用。
