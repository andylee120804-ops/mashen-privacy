# 版本 1.2.1 提审说明（AGC Review Notes）

> 提交版本：**1.2.1（versionCode 1000003）**
> 提交日期：2026-08-31
> 适用对象：华为 AppGallery Connect 审核员
> 本文档为审核辅助说明，不随应用打包，供提审时在「版本说明」中参考。

## 一、本版本修复内容（相对 1.2.0）

1. **UI 布局对齐修复**
   - 首页黄历卡「宜 / 主神 / 忌」三列：中列行数多于左右列导致顶部标签基线错位，改为三列顶部对齐，标签统一基线。
   - 「我的」页牌运汇总区（赢 / 输 / 平 / 净盈亏 / 胜率）：三列高度不同导致居中错位，改为顶部对齐；「赢 / 输 / 平」行内小标签与数字改为底部对齐，文字基线一致。
   - 还愿页心愿列表：右侧「还愿 / 已还愿」徽章由整行垂直居中改为与左侧内容元信息行底部对齐，视觉一致。
   - 排行榜条目：排名 / 昵称 / 次数 / 磕头四段文字字号不同（16 / 14 / 14 / 12）导致基线错位，改为底部对齐统一基线。

2. **底部导航条避让（≥28vp）**
   - 祈福页「磕头 / 完成祈福」按钮区：沉浸式全屏下由屏幕 94% 高度上移至 88%，按钮底部距屏幕底缘 ≥28vp，不再与系统导航条 / 手势条重叠。
   - 排行榜页底部「刷新」按钮：根容器增加底部安全区下边距，按钮不再压入导航条区域。

3. **云端测试数据清理**
   - 提审前已清空 Cloud DB「Wish（心愿）」「Leaderboard（祈福排行榜）」两表的开发 / 测试数据，确保审核员首次进入应用时无默认 / 测试数据残留。

4. **隐私披露修复（对应审核问题1：隐私标签与应用实际情况不符）**
   - App 内隐私政策（PrivacyDialog.ets）原文案声称「所有信息仅存储在设备本地，不会上传至任何服务器」，与实际云服务行为不符。已重写为如实披露：祈福统计、脱敏昵称、设备匿名标识符上传至华为云用于排行榜；心愿内容上传至华为云并公开于心愿墙；其余记录仅存本地；用户可删除心愿、清除本地记录。
   - 控制台「隐私标签」已按实际收集项勾选：设备标识符（匿名）、昵称（脱敏）、用户生成内容（文本）、操作记录。详见 `docs/privacy-label-checklist.md`。
