# AGC 隐私标签填写指引（麻神保佑 v1.2.1）

> 对应审核拒因：**问题1「应用内存在收集个人信息行为，但未勾选隐私标签，与应用实际情况不符」**
> 依据：App 实际上传了脱敏昵称、设备匿名标识符、祈福行为数据、心愿内容至华为云（Cloud DB + 云函数），控制台「隐私标签」必须如实勾选。
> 参考文档：《AppGallery隐私标签服务说明》https://developer.huawei.com/consumer/cn/doc/privacy-label

## 控制台入口

**AppGallery Connect → 我的应用 → 麻神保佑 → 应用信息 → 隐私标签**（或「用户与权限 → 隐私标签」），逐项勾选并填写收集目的。

## 必须勾选的项目（对应实际收集行为）

| 类别 | 勾选项 | 收集的信息 | 使用目的（建议填写文案） |
|------|--------|-----------|--------------------------|
| 设备信息 | **设备标识符（匿名设备标识符）** | `deviceUserId`（应用启动时随机生成的匿名 ID，非 OAID/IMEI） | 用于区分不同用户的祈福记录与心愿归属，实现排行榜与心愿墙功能 |
| 用户基本信息 | **昵称** | 祈福者输入的姓名，云端仅存脱敏形式（首字 + \*\*\*） | 用于在祈福排行榜、心愿墙展示用户昵称 |
| 用户生成内容 | **文本内容** | 心愿墙发布的许愿 / 还愿文字 | 用于实现许愿、还愿功能，并向所有用户公开展示 |
| 网络使用数据（使用记录） | **操作记录 / 使用记录** | 祈福次数、磕头次数、连续签到天数 | 用于统计并生成祈福排行榜 |

## 不需要勾选（未收集，切勿误勾）

- 位置信息、通讯录、相册、相机、麦克风、生物识别、健康医疗、财务信息、身份信息 —— **均未收集**
- 日志信息（崩溃日志 / 运行日志）—— 无日志上报 SDK，不勾
- 传感器数据 —— 加速度计仅用于求签页摇晃出签，**实时读取、不上传不存储**，不属于信息收集 → 隐私标签**不勾**；
  但 AGC 检测器把「获取加速度传感器」视为需披露行为，**隐私政策（App 内 + 托管网址）必须说明**（见下节 2026-09 拒因）

## 各勾选项的补充字段（如实填写）

1. **收集方式**
   - 设备标识符 / 行为数据：自动收集（应用运行过程中自动生成并上传）
   - 昵称、心愿内容：用户主动提供（祈福时输入姓名、发布心愿时输入内容）
2. **是否与第三方共享**：否。数据仅由华为云（AppGallery Connect 云服务）处理与存储，应用不接入任何广告 / 统计 / 第三方数据分析 SDK。
3. **是否跨境传输**：云服务部署在中国大陆区域，数据存储于中国境内，不涉及跨境传输（若 AGC 项目区域非中国大陆请按实际情况填写）。

## 与 App 内隐私政策的一致性

App 内隐私政策（`entry/src/main/ets/components/PrivacyDialog.ets` 的 `getPrivacyContent()`）已同步更新，如实披露：
- 祈福统计、脱敏昵称、设备匿名标识符上传至华为云用于排行榜；
- 心愿内容上传至华为云并公开于心愿墙；
- 其余记录仅存设备本地；
- 用户可删除心愿、清除本地记录。

控制台勾选内容必须与 App 内政策一致，避免再次以「不一致」被拒。

## 2026-09 复检拒因：加速度传感器未在隐私政策说明

检测器结论：「应用获取用户信息：加速度传感器，但未在应用内隐私政策 / AGC 提交的隐私政策网址中说明」。

### 根因（代码侧，已修复）

上一提交版本（HEAD）的 QiuQian 求签页已调用 `sensor.SensorId.ACCELEROMETER`，但
module.json5 未声明该权限、无权限用途文案、无任何隐私披露 → 检测器判「未说明」。
